# 首版产品范围

更新日期：2026-11-21。

本文件记录已确认的产品范围。后续规划与实现以此处的最新决定为准；调研报告中的题型、题目与答案分析属于历史材料研究，不自动构成功能要求。

## 已确认

- 首版面向六级备考，使用平台为 Windows。
- 核心围绕文章和单词之间的联系：阅读文章、主动选词、保留原句与完整原文的关联，并在复习时回到阅读语境。
- 选词由学习者发起，支持单个词和短语；既包括不认识的表达，也包括认识但觉得值得学习的表达。
- 复习可以从词汇记录回到原文，也可以通过重读原文再次遇见所选词。
- PDF 是当前重点讨论的文章来源。导入目标调整为整理可阅读、可选词、可回查来源的文章。
- 首批材料限定为 2023—2026 年的 21 份六级 PDF，逐份清单及 SHA-256 见 [首批材料清单](./first-batch-pdfs.json)。
- 首批正文范围为仔细阅读和长篇匹配的完整英文文章。题干、选项、考试说明、答案和解析不进入文章库。
- 本轮仍以形成双方认可的首版产品说明为目标。

## 已确认的阅读与选词体验

- 主要阅读界面显示重新排版的文章正文，支持调整字号和行距，并保留打开原 PDF 对照的入口。
- 默认沿用先阅读圈词、后集中查词的节奏。阅读时圈选词或短语，正文做高亮，并保存对应原句与出处。
- 读完文章后可在正文底部显式选择「读完并整理本篇选词」，集中查词和整理学习内容。

## 已确认的阅读界面与原文对照

- 阅读界面单栏居中，正文列宽 620px；字号 16/18/20/22 四档（默认 20）、行距 1.6/1.8/2.0 三档（默认 1.8），设置随用户记住。
- 长篇匹配在段首显示原卷段落字母（A–P），仔细阅读不显示；暂不做侧边段落导航。
- 原文注释默认以浅色小字显示在原词后，可一键隐藏、状态记住；选词、复制与交给模型的文本使用剥离注释后的正文。
- 词状态以颜色为主：已收集为琥珀色、稍后看为蓝色、本次选中为麦色底；下划线只作辅助编码，文字色对比度须达 4.5:1（浅色纸约 `#8F5A1A`、`#2F5FA8`）。
- 原 PDF 以右侧抽屉内嵌（pdf.js），可拖动宽度，窄窗口下改为覆盖层；从原句进入时跳到所在页并高亮该句，定位失败依次退到段落、页并提示。
- 记住每篇最后读到的段落与句子；文章列表按 7 个场次分组，显示题型、词数与该篇阅读进度；首页提供“继续阅读”。
- 文章底部的「读完并整理本篇选词」视为读完该篇；顶栏查看与文章库入口只读，不会把未读完的篇目标成 100%。已读完可以收回，收回只清完成标记，保留阅读位置、本篇设置与已收词条。

## 已确认的视觉与设计 token

- 视觉方向取 D 素读，管理页吸收三栏做法；全部数值见 [界面 token 表](./ui-tokens.md)，实现直接照抄。
- 浅色：纸 `#FBFAF3`、面板 `#FFFEF9`、墨 `#1A1A17`、次级 `#6E6A5E`、琥珀 `#8F5A1A`、蓝 `#2F5FA8`、麦底 `#F2E4BE`、危险 `#B4432A`、线 `#E6E0D0`。深色：纸 `#1A1A1E`、面板 `#22221F`、墨 `#E8E4DA`、次级 `#A8A29A`、琥珀 `#D9A441`、蓝 `#7FA7E8`、线 `#33322D`；不用纯黑。
- 正文与 12px 以上文字的对比度 ≥4.5:1，数值逐色实测；琥珀不作大段正文色；原型里 2.92:1 的提示色 `#9A9384` 作废，统一 `#6E6A5E`。
- 阅读正文随包分发 Source Serif 4（OFL、可变），回退 Sitka / Georgia；界面用 Segoe UI Variable + Microsoft YaHei UI，中文最小 12px。
- 间距 4/8/12/16/24/32/48；圆角 4/8/10/14/999；阴影两级；焦点为 2px 琥珀描边；动效 150–180ms 且尊重 `prefers-reduced-motion`。
- 布局：阅读列 620、对话列 760、对话栏 236、钉板 336（收起 44）、管理页三栏 240/1fr/320；断点 1100/1000/900。

## 已确认的词条组织与收集体验

- 同一个词或短语归到一个词条下，词条关联多条来自不同阅读语境的原句，分别保留出处与返回文章的关系。
- 常见词形变化归到同一词条，例如 approach、approached、approaching；原句和其中的实际词形保留原样。approachable 这类派生词独立成词条。
- 同一篇文章、同一句话中重复圈选同一表达，只保留一条原句关联；遇见新的原句时增加收藏。
- 原句不断积累的“收集感”是用户特别强调的核心体验。词条展示已收集原句条数和来源文章数；每次新增时，清楚展示刚收下的原句。

## 已确认的词条浏览与修改

- 原句按文章分组，组内按句序；组头显示篇名与该篇贡献的条数。
- 每条原句提供：回到原文、重新圈定（替换选错的范围）、删除；同篇前后句悬浮展开查看。
- 选错范围只能重新圈选，不直接编辑原句文字，保证原句与原文逐字一致。
- 词条页的“更多”里可合并词条、把某条原句拆到新词条或另一个词条、更换主词形。
- 词条列表默认按最近收集排序，可切换字母序；搜索同时匹配词条名与已收原句文本；筛选先做“有/无学习内容”。
- 删掉最后一条原句时，提示后连同该词条的学习内容一并删除。

## 已确认的学习内容与生成文章整理

- 词条页里已保存的学习内容可就地编辑（点击编辑、保存后按 Markdown 渲染），可删除、可置顶一条；不保留历史版本，保存后以最终稿为准。
- 学习内容可移到另一个词条，入口与“把原句拆到…”并列在词条页的“更多”里。
- 搜索覆盖词条名、已收原句文本、学习内容正文与生成文章正文；结果按“词条 / 文章”分组，点进去落到命中位置。
- 文章库里生成文章与真题文章同列，但标“AI 生成”，可按来源筛选真题 / AI；可重命名、删除；不做标签体系。

## 已确认的 LLM 辅助方向

- LLM 接受学习者自己的要求，任务和输出形式保持可定制，不将学习辅助固定为统一的语境词义讲解。
- 学习对象可以是一个词、短语、原句，或学习者选定的一组词。
- 用户希望按需获得词义、简单例句、相近短语、近义词、多义词说明、各种助记，以及包含多个目标词的文章等学习内容。
- 用户可保存自己的常用学习指令，之后调用、修改和复用。
- 生成结果先展示，由用户挑选、修改后保存到对应词条；用户可以继续生成或改写，再留下喜欢的内容。
- 用一组词生成的文章可以保存到文章库，明确标注“AI 生成”，并支持阅读、选词和回链。
- 首批外部导入材料仍为既定 21 份 PDF；生成文章是围绕所收词汇制作的学习材料，不扩展外部 PDF 范围。
- 各类学习内容保留来源信息。AI 直接生成的例句属于生成内容；在生成文章中阅读选词形成的原句记录，以该生成文章为来源。

## 已确认的学习指令与生成流程

- 学习指令是自由文本，旁挂几条内置示例（词义与用法、例句、近义辨析、助记、多义词、生成文章）可一键填入；不锁定格式，不使用占位符语法。
- 保存的指令有名称，可修改、删除、复制；调用时以保存的指令为起点继续编辑。
- 上下文面板固定在输入框上方：词条与原句对话默认带所选词及原句，文章对话默认带全文。任意对话均可搜索并添加文章全文、段落、词条、原句和学习内容；阅读时跨句选中的摘录也可带入。全文与同篇段落不重复添加，各项可单独移除，摘要按实际材料显示数量与约略字数。
- 生成结果用版本式结果卡：重新生成或改写产生新版本，可在卡上切换；输出达到模型上限时可“继续生成”，新内容接在同一版本后。
- 生成过程中发送键变成停止键，输入区不锁死；停止或出错时保留已输出内容，可保存但要标“未完成”；已经输出正文或思维链后不自动重试，保留已输出内容，重试从头发起；停止会抑制重试。按 provider 配置的重试策略只对可重试错误生效（默认只重试临时错误，最多 5 次，也可改为所有错误）。
- 保存动作统一为“钉住”：从生成结果里选中片段钉住，落点三态为词条 / 文章 / 未归档，不按长度或内容自动判断（规则见下文“已确认的对话与钉住收录”）。
- “存为文章”仍是独立动作：把整次生成存为文章库里的新生成文章，与钉住的“文章”落点（挂到已有文章）不是一回事。
- 一次可对一组词生成：词条列表多选后“用这些词学习”，或在自由学习里添加词条；一次最多 20 个。
- 错误按类型给具体提示与动作（更换密钥、余额不足、限流、服务繁忙、网络异常），只有可重试的错误显示重试。

## 已确认的对话与钉住收录

- 只钉 AI 回复；自己发的提问不钉，保存常用问法走“学习指令”。
- 钉住的最小单位是选中片段：连续文本，可跨段落；“钉整条”只是选中全段的快捷。选一个词也能钉，钉住本身不产生原句。
- 落点三态：
  - 词条：成为该词条的一条学习内容，可就地编辑、置顶、删除，编辑后即最终稿（不保留历史版本）；出处作为只读小字附着。
  - 文章：挂到一篇已有文章（真题或生成文章）下，成为“这篇的钉住”，可回链到段落与原句；钉住不会新建文章。
  - 未归档：暂存，钉板里显示条数，可一键归位；不计入首页“最近收集”、词条列表与文章库计数。
- 默认落点由对话主对象推导：挂词条 → 该词条，挂原句 → 该原句所属词条，挂文章 → 该文章，空白对话 → 未归档。弹层预选这个默认，回车即钉；用户手动改过就以改为准，记到本对话结束，对话主对象变了重新推导。
- 一条钉住只有一个落点，可随时移动（移动 = 改落点，不复制）；同一片段要挂两处就再钉一次，各自独立。
- 钉住绑定当次生成（条目与片段位置）：之后改口、重新生成都产生新版本，旧钉住不动；要收新版本就再钉一次。
- 钉完 5 秒内可撤销；之后从落点删除。删除即真删，不留墓碑、不做回收站；源对话里那片段的“已钉”角标随之消失。
- 源对话被删，钉住仍保留（快照仍在），“看原对话”置灰并说明已删。
- 钉住卡固定显示出处行：对话名、第几轮、模型、时间、当时的原句（原句后来被删也显示快照）。点“看原对话”打开对话、滚到该条、底色提示；该条不在当前分支时先只读展示并提示“这条在另一分支”，提供“切到此分支”，不自动切换。

## 已确认的聊天页与思维链

- 聊天页取左栏对话列表（标题右侧显示未归档条数）+ 宽单栏对话 + 底部输入框；不做每条回复的常驻右侧动作轨，也不做卡片流。
- 钉住入口两处：消息悬停浮出工具条（钉住 / 复制 / 重写），选中片段浮卡（钉住 / 复制 / 解释）。
- 空对话标题为“新的学习”，副标题“从词或文章开始”，给三条起手式；上下文行显示“还没有带上上下文”。
- 流式中发送键原地变红色停止键，Esc 同效；输入区不锁；停止后保留已输出内容，标“已停止 · 未完成”。
- 长回答超过 3 段或约 1.2 屏折叠，折口显示“还有 N 段 · 全文约 M 字”，可再收起；流式中不折，回答结束才折。
- 出错只在这一条消息里就地显示，不加顶部汇总横条；给重试 / 换模型 / 查看设置，已输出的正文保留并标“未完成 · 未保存”。
- 编辑上一条在输入框上方提示“发送后会新建分支，原来的回答保留”，Esc 取消；重新生成产生新版本，不覆盖旧版。
- 键位：Enter 发送（跳过输入法组合态）、Shift+Enter 换行、Esc 停止或关闭弹层；不做方向键快捷键，设置里提供“Ctrl+Enter 发送”开关。
- 思维链折在回答正文上方一行：流式中展开并显示“正在思考…”与计时，正文一到自动折成“已思考 N 秒”，点击展开后在本对话内记住；内容超过约 8 行内部滚动。
- 思维链不可钉，选中只给复制；进条目日志可回看，但不回传给模型、不进压缩摘要；模型不返回思维链时整行不出现，首 token 前用三点等待态。
- 对话默认开启思维链（思考强度固定 `high`，首版不在界面暴露）；接入层必须显式传强度，否则服务端会回到“关闭思考”，界面那块永远不出现。

## 已确认的钉板与未归档

- 钉板是右侧抽屉：默认收成 44px 窄条并显示未归档条数，点开占 336px，正文仍按 720px 居中；钉住瞬间不自动打开。
- 抽屉分两个 tab：「当前对话」与「未归档 N」。卡片含三行截断的摘录、出处行（轮次 · 模型 · 时间 · 落点标签）与动作：已钉的给看原对话 / 换落点 / 删除，未归档的给归到词条 / 归到文章 / 丢弃。页脚显示当前 tab 计数，右侧分别是「在词条中查看」与「全部归位」。
- 空状态写「没有未归档」；左栏的「未归档 N」与顶栏的「钉板 N」都打开抽屉并切到对应 tab。
- 钉住反馈：toast「已钉到词条 lament · 撤销」保留 5 秒；被钉段落左侧琥珀竖条常驻，角标只在刚钉时出现；抽屉里新钉的卡片描边几秒后消失。
- 未归档不做独立页，不做按对话分组与批量选择，等条目真的变多再议。
- 丢弃与「全部归位」都是先执行、再给可撤销提示，不加二次确认；唯一例外是源对话已删除的快照，丢弃前先提示「这是对话被删后仅存的副本」。
- 从词条学习内容点「来源」：打开该对话、滚到那条、底色高亮到点击别处，顶部横条写「来自词条 × · 学习内容」并留「回词条」；同屏右侧继续显示那张词条卡。

## 已确认的词条页与文章库

- 词条页三栏：左词条列表 240、中原句列 640、右栏 320；窗口 <1100px 时右栏折成抽屉，退回两栏。
- 右栏默认收窄，点开才铺开主词形与变体、学习内容与「更多」；打开词条先看到原句。
- 原句按文章分组，组头是篇名与该篇贡献条数，组内按句序；每条给回到原文 / 重新圈定 / 删除，悬停与键盘聚焦都出现，窄窗口 <900px 改常驻小图标行。
- 学习内容卡片支持置顶一条、编辑、移动、删除，底部固定来源行并带「看原对话」；「更多」里是合并词条、拆分原句、换主词形、移动学习内容。
- 词条页空态：未选词条时中栏提示「在左边选一个词条」；无学习内容时右栏写「还没有学习内容 · 从对话里钉一段进来」。
- 文章库真题按场次从新到旧、场次内按第1套至第3套分组；套内固定为长篇匹配、仔细阅读 Passage One、Passage Two，不受阅读进度影响。场次、套与 AI 生成区均可折叠，首次只展开选中文章所在组，切页保留展开态；搜索时显示扁平命中列表。套内默认篇名简写为题型，自定义篇名保留并补充题型线索。
- 文章库右侧详情面板给篇名与场次、词数、进度、收词条数、最近打开，动作是继续阅读 / 重命名 / 删除，下面是「本篇收过」。
- 阅读进度只写文字（未读 / 读到一半 / 已读完 + 百分比），不做进度条；AI 段为空时提示「用一组词生成第一篇」。

## 已确认的内置词典

- 内置一份不调用模型的离线词典，只做“查”：回答“这个词是什么”，语境义仍交给 LLM 或自己写。
- 三处入口：阅读页划词卡首屏显示音标与按词性分条的中文释义（前三条展开，其余折叠）；词条页右栏学习内容上方一块只读“词典”；对话里选中词时浮卡多一个“释义”。
- 任一条释义可“用这条起草”，把词形、音标与那条释义填进学习内容编辑框当草稿，用户改完显式保存才入库；不自动写入、不批量导入。
- 词库取 ECDICT（MIT），裁剪为两万核心词 + 四六级/六级标签 + 63 篇语料出现的词 + lemma 表，约 3–5 万条随包；查不到时提示“没收录 · 去问 LLM”，不猜、不用拼写算法硬凑。
- 词形归并直接用 ECDICT `exchange` 字段的 `p/d/i/3/s/r/t` 与 lemma，不另写词形还原。
- 不做背单词与测验、例句库、多词典切换、在线词典聚合、发音；分发物保留 ECDICT 的版权声明。

## 已确认的设置页

- 左导航：模型服务 / 阅读 / 外观 / 数据 / 关于，右侧单列表单。
- 模型服务是提供商列表 + 新增卡片。每套显示 Provider ID、显示名、协议、接口地址、模型目录、密钥来源三态、验证状态与「使用中」，可切换、编辑、删除；切换只影响之后的调用，不改历史对话与钉住。
- 新增分「内置提供商」与「自定义 API」两条路。内置提供 DeepSeek、Kimi、智谱 GLM、MiniMax、OpenAI、Anthropic、Google Gemini、xAI 与 OpenCode GO；自定义 API 可选 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与 Gemini API。四种协议复用同一套流式正文、思维链、停止与错误分类；OpenCode GO 直接复用 pi 内置聚合提供商，使用请求级密钥与模型自带的协议、地址。Provider ID 小写字母开头、唯一且创建后不可改，单协议提供商的协议创建后不可改。
- 模型目录可手加、行内编辑、删除、拖动或用上移/下移排序，并选一条默认模型。自定义提供商至少要有一个模型；删默认模型前须先另选，目录不能被删空。未知模型 ID 可加入并发送，缺容量时按上下文 1,000,000 / 输出 128,000 / text 兜底。OpenCode GO 的模型目录首版只读，只能选默认模型。
- 「获取可用模型」是显式动作：内置目录直接返回本地目录、不联网；自定义 API 用当前表单地址与凭据取回候选，勾选后才加入，不自动覆盖已有模型；响应上限 4 MiB，失败保留已有目录。
- 密钥来源三态为「本机 / 环境 / 缺失」：环境变量名可编辑；环境模式不写密文；缺失时发送前明确报错并点名变量，不静默换源；本机密文解不开也明确报错。从本机切到环境变量须先确认并清除已存密文，取消保持原配置。
- 保存不联网、状态为「未验证」；卡片上的「测试连接」是显式动作：按这套提供商的协议发一次最小请求，8 秒超时；收到首段正文、思维链或正常结束即算通过，通过后转「已验证」，显式测试失败会收回已验证。失败保留原配置与原密钥并显示原因与 request id。真实对话成功一次后同样自动转「已验证」；真实对话失败只记录最后错误，不降级已验证状态。
- 阅读设置放全局默认（字号 20、行距 1.8、注释显示、弱高亮），阅读页面板改本篇覆盖值，两处标注当前值来自全局还是本篇。
- 外观支持浅色 / 深色 / 跟随系统，深色取 token 表里那一套值。
- 数据区给立即备份、打开数据目录、从备份恢复、导出单条对话 JSONL；恢复确认只两个按钮，说明整体替换、替换前自动留快照。备份包含提供商、模型目录与环境变量引用，不含任何密钥密文。
- 关于区列版本、ECDICT（MIT）版权声明与两份 ADR 的指向。

## 已确认的应用外壳与首页

- 左侧全局栏 238 宽，六项：首页 / 阅读 / 词条 / 对话 / 文章库 / 设置，有计数的项把数字挂在右侧；栏底写「离线可用 · 模型调用按设置」。

- 首屏空态：标题「先读一篇」+ 一句说明 + 两个动作（从文章库挑一篇 / 用一组词生成）；最近收集与稍后看各给一行小字空态。

## 已确认的自主复习与学习上下文

- 软件提供文章、词条、原句、个人学习内容和 LLM 工具的平台，复习内容与使用方式由学习者自主组合，不强制一条固定复习路线。
- 打开词条时默认先展示已收集的原句，释义、助记等学习内容可展开查看。默认展示顺序不限制用户采用其他复习方式。
- 调用 LLM 时，词条或原句对话默认带上所选词和原句，文章对话默认带全文；其他文章、段落、原句、摘录和学习内容由学习者自由选择。
- 学习上下文可查看、可选择，便于学习者控制模型这次参考的材料。

## 已确认的复习与重读

- 首页三块：继续阅读（最近一篇没读完的）、最近收集的词条、进文章库的入口；不做统计仪表盘与学习时长。
- 提供手动“稍后看”标记，首页单列显示；不做按时间或遗忘曲线的自动排程。
- 重读原文时，本篇收过的表达做弱高亮（与本次圈选区分），点击弹出词条卡；可在阅读设置里关闭。
- 从词条回到原文时，跳到那条原句、滚到眼前、句子底色高亮，顶部提示“来自词条 × · 回词条”，高亮保留到点击别处。
- 复习只做浏览式：词条列表逐条看、按文章重读；不做卡片翻转型逐条过，也不做自测。
- 只记录词条与文章的“最近打开”时间，用于首页继续复习与词条列表次级排序；不做复习次数、连续天数与正确率。

## 已确认的技术方案

- 桌面形态为 Electron 45 + TypeScript：界面用 Chromium，模型调用的 `@earendil-works/pi-ai@1.5.2` 跑在主进程（Electron 内置 Node 24.22.3，满足该包 Node ≥22.19 的要求）。
- 本地数据存 SQLite 单库，覆盖文章、词条、原句、学习指令、学习内容与模型提供商、模型目录；源 PDF 不入库，按 SHA-256 与页码引用。
- 本机保存的 API 密钥用 Windows DPAPI（Electron `safeStorage`）单独加密保存，环境变量模式只存变量引用；密钥默认不进备份，备份为数据库快照，恢复整体替换，替换前自动留一份当前快照。
- 首个真实接入路径为 OpenAI Chat Completions；提供商、地址、模型目录与凭据来源在软件内填写，验证流式增量、中途停止、错误提示与部分结果保留。
- 首批接入只支持一套服务也可工作，但配置允许多套保存与切换。
- 会话按不可变条目日志存 SQLite（父指针 + 对话叶子），超窗以摘要条目追加、原文保留；钉住存快照与出处，单条对话可导出 JSONL。详见 [ADR 0003](./adr/0003-session-storage.md)。
